# EquiWarp
把一张等距柱状投影(Equirectangular) 全景图，通过扭曲变形(Warp) 动画平滑过渡为可自由探索的球面环境

### 焚决
···
【代码描述】
【全景图格式】
一张**等距柱状投影全景图（Equirectangular Projection）**。
在图中界面的 **Mapping（映射）** 选项中明确显示为 **Latitude Longitude Layout（经纬度布局）**，这是 360 度全景图

【需求】
新建一个文件。观者可以看到完整2d全景图，然后慢慢闭合，到变成一个环境的threeJs样例。一个页面选择全景图和设置开头动画播放时间，然后在进入环境之后成开头可以设置灵敏度。进入全景图之后根据鼠标移动改变视角。开头有一个按钮“录制模式”：按下马上将网页设置成全屏。可以在按下生成全景环境之后，动画开始播放之后把鼠标按键影藏，也不显示提示视角操作方式的UI。另有一个选项鼠标旋转视角平滑。可以设置值。单html文件

【开头动画的详细描述】
对于开头的动画：如果全景图是一个球体，摄像机在内部。外面是全景贴图。你需要保证一开始全景贴图的2d的时候正对摄像机，此时可以看到平面的贴图。然后贴图逐渐弯曲，慢慢变成一个球体，从而实现全景图变化的效果。有几个关键点，1：观者一直在内部，可以看到贴图的变化。2：此效果原理是球面上的贴图逐渐放大，找到正确的位置，变成全景贴图的过程。3.技术上来说，开头是摄像机视角贴图在球面上的投影，结尾是完整包裹的全景图。
